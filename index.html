Koleksi Formula Hook & Framework Caption Viral

3 detik pertama menentukan 90% kesuksesan postingan media sosial. Salin template hook di bawah dan gunakan struktur caption terbukti untuk melonjakkan retensi dan engagement.

AIDA

Formula AIDA

Attention → Interest → Desire → Action. Sangat cocok untuk konten promosi produk, kursus, dan pengumuman fitur baru.

PAS

Formula PAS

Problem → Agitate → Solution. Paling ampuh untuk konten edukasi dan carousel solusi masalah audiens.

BAB

Formula BAB

Before → After → Bridge. Cocok untuk studi kasus bisnis, transformasi, behind the scenes, dan testimoni.

Panduan Penggunaan ContentFlow

Pelajari cara memaksimalkan fitur ContentFlow mulai dari brainstorming ide, meracik copywriting viral, mengatur alur kerja produksi tim, hingga penjadwalan konten media sosial dan artikel Blogspot Anda.

Alur Kerja 5 Langkah untuk Pemula

Ikuti urutan ini untuk mengelola konten dengan rapi dan konsisten.

1

Catat di Bank Ide

Kumpulkan ide spontan kapan saja di tab Bank Ide. Jangan biarkan ide hilang sebelum sempat dieksekusi.

2

Cari Hook Viral

Gunakan 13 formula Hook 3 detik & framework caption AIDA/PAS di tab Hooks agar audiens tidak langsung skip.

3

Jadwalkan Konten

Klik tombol "+ Konten" untuk memasukkan judul, platform, pilar tema, tanggal & jam tayang, serta skrip caption.

4

Geser di Kanban

Tarik & lepas kartu (drag & drop) dari tahap Ide → Scripting → Desain → Review → Siap Tayang.

5

Pantau Kalender

Tinjau seluruh jadwal bulanan di Kalender. Klik tanggal kosong untuk langsung menambah jadwal di hari itu.

Panduan Khusus Pengguna Blogspot / Blogger

Cara memaksimalkan ContentFlow untuk mengelola artikel blog Anda.

1. Merencanakan Kalender Artikel Blog

  • Saat membuat konten baru, pilih Platform: Blogger / Blogspot dan Format: Artikel / Blog Post.
  • Tuliskan Keyword / Kata Kunci SEO Target di bagian judul artikel.
  • Gunakan kolom Catatan untuk menyusun kerangka artikel (*H2, H3, referensi link internal*).
  • Gunakan kolom Hook untuk merancang paragraf pembuka yang memikat pembaca agar membaca hingga selesai.

2. Memasang (Embed) Planner ke Halaman Blogspot

Anda bisa memasang aplikasi ini langsung di dalam blog Blogspot Anda (di halaman khusus/dashboard): 

<iframe src="https://prihantowahyu.github.io/Coplan/" width="100%" height="800px" style="border:none; border-radius:12px;"></iframe>
*Masuk ke Blogger → Halaman → Tambah Halaman Baru → Pilih mode HTML dan tempel kode di atas.

Aturan Golden Ratio Konten (80 : 20)

Agar akun Anda tidak dianggap akun jualan yang membosankan oleh audiens, gunakan pembagian pilar ini:

📚 80% Konten Value (Edukasi, Tips, Hiburan) Followers & Trust
🏷️ 20% Konten Jualan & Promosi Penjualan / Cuan
